# 나의 첫 금융투자

청소년을 위한 금융교육 웹 게임입니다.
초기 자금 **1,000,000원**으로 **10년 동안** 예금·주식·콜옵션 3가지 상품에 투자해 보며 아래 3가지를 체감합니다.

1. **금리** — 기준금리가 경제 상황에 따라 바뀌고, 예금 이자도 달라진다.
2. **장기투자** — 뉴스에 흔들려 자주 사고팔면 수수료와 타이밍 실패로 손해 보기 쉽다.
3. **고위험 상품** — "최대 10배 수익"을 내세우는 상품은 원금을 모두 잃을 수 있다.

게임 중 용어 옆 📘 버튼, 상단 📚 개념 노트, 최종 결과의 개념 정리 노트를 통해 한국은행·금융감독원·투자자교육협의회 공식 자료로 더 공부할 수 있습니다.

> 본 게임은 교육용이며 실제 투자 권유가 아닙니다.

## 파일 구조

```
my-first-investment/
├── index.html    # 화면 구조 (시작 / 게임 / 연말 팝업 / 최종 결과 / 개념 모달)
├── style.css     # 디자인, 반응형, 인쇄용(PDF 저장) 스타일
├── script.js     # 게임 규칙·계산·그래프(canvas)·화면 동작
├── concepts.js   # 공식 링크(OFFICIAL_LINKS) + 금융 개념 데이터(CONCEPTS)
└── README.md     # 이 문서
```

- 순수 HTML/CSS/JavaScript만 사용합니다. (React·npm·빌드 과정·외부 라이브러리·CDN 없음)
- 모든 파일은 같은 폴더에 있어야 합니다.

---

## 로컬에서 실행하기

1. 다섯 개 파일을 한 폴더에 저장합니다.
2. `index.html` 파일을 **더블클릭**하면 웹 브라우저에서 바로 실행됩니다.

서버 설치가 필요 없습니다.

## 유튜브 링크 넣는 방법

`concepts.js` 맨 위의 `OFFICIAL_LINKS`에 유튜브 주소가 **자리표시자**로 들어 있습니다.

```js
YOUTUBE_BOK: {
  org: "한국은행",
  title: "한국은행 공식 유튜브",
  url: "YOUTUBE_BOK" // ← 여기를 공식 유튜브 주소로 바꾸세요
},
YOUTUBE_FSS: {
  org: "금융감독원",
  title: "금융감독원 공식 유튜브",
  url: "YOUTUBE_FSS" // ← 여기를 공식 유튜브 주소로 바꾸세요
}
```

- `"YOUTUBE_BOK"`, `"YOUTUBE_FSS"` 부분을 **공식 채널 또는 영상 주소**(`https://`로 시작)로 바꿔 저장하세요.
- 자리표시자 그대로이면 해당 버튼은 화면에 **자동으로 숨겨집니다.**
- 바꾼 뒤 브라우저를 새로고침하면 버튼이 나타납니다.
- 채널 주소는 반드시 공식 채널인지 직접 확인한 뒤 넣어 주세요.

## GitHub에 올리기

1. [GitHub](https://github.com)에 로그인 → 오른쪽 위 **+** → **New repository**
2. 저장소 이름(예: `my-first-investment`)을 입력하고 **Public**으로 만들기 → **Create repository**
3. 저장소 화면에서 **uploading an existing file** 클릭
4. `index.html`, `style.css`, `script.js`, `concepts.js`, `README.md` 다섯 개 파일을 끌어다 놓기
   (폴더째가 아니라 **파일들이 저장소 맨 위에** 오도록 올려야 합니다.)
5. 아래 **Commit changes** 클릭

## Render 무료 플랜 Static Site로 배포하기

1. [Render](https://render.com)에 가입/로그인 (GitHub 계정으로 로그인하면 편리합니다.)
2. 대시보드에서 **New +** → **Static Site** 선택
3. GitHub 연결 후 방금 만든 저장소 선택 → **Connect**
4. 설정값을 아래처럼 입력합니다.

| 항목 | 값 |
|---|---|
| Name | 원하는 이름 (예: `my-first-investment`) |
| Branch | `main` |
| Root Directory | 비워 두기 |
| **Build Command** | **비워 두기** |
| **Publish Directory** | **`.`** (마침표 하나) |

5. **Create Static Site** 클릭 → 잠시 후 `https://○○○.onrender.com` 주소가 생깁니다.
6. 이후 GitHub에서 파일을 수정하면 Render가 자동으로 다시 배포합니다.

## 게임 규칙 요약

| 항목 | 규칙 |
|---|---|
| 현금 | 이자 없음 |
| 예금 | 예금금리 = 기준금리 + 0.5%p, 자유 입출금, 1년마다 복리 이자(원 단위 버림) |
| 주식 '미래전자' | 그해 시작가로 1주 단위 매매, 매매 금액의 0.5% 수수료(원 단위 올림) |
| 콜옵션 | 1계약 10,000원, 행사가 = 현재 주가 × 1.3, 1년 뒤 주가가 행사가 미만이면 소멸(전액 손실) |
| 종료 | 10년 후 주식은 15,000원에 청산(수수료 0.5%), 예금·현금 합산 |

비교 기준값(코드에서 같은 규칙으로 직접 계산):

- 예금만 했다면: **1,417,211원** (약 141.7만원)
- 1년차에 99주를 사서 끝까지 보유했다면: **1,482,625원** (약 148.3만원)
